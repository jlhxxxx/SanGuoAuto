# SanGuoAuto

SanGuoAuto 是一个运行在困鱼 / AutoJS 上的《三国：冰河时代》自动化脚本项目。

当前 1.0.0 版本支持三个任务：

- 讨伐
- 集结
- 华佗

脚本不会自动启动游戏，也不会校验当前应用。使用前需要先手动进入游戏，并停在要执行任务的界面。

## 免责声明

本项目仅用于个人学习、研究和自动化测试。游戏账号、游戏规则、平台风控等风险由使用者自行承担。

## 准备环境

1. 手机上安装困鱼或兼容 AutoJS 的运行环境。
2. 把本项目复制到手机可访问的脚本目录。
3. 在困鱼 / AutoJS 中打开项目，并选择 `main.js` 运行。
4. 按提示授予截图权限和悬浮窗权限。

## 使用教程

1. 手动打开《三国：冰河时代》，进入要执行任务的起始界面。
2. 在困鱼 / AutoJS 中运行 `main.js`。
3. 等浮窗出现后切回游戏界面。
4. 点击浮窗里的任务名，选择“讨伐”“集结”或“华佗”。
5. 点击“次数”旁边的数字，输入循环次数；默认是 `200`。
6. 点击“开始”，脚本会循环执行当前选中的任务。
7. 运行中可以点击“暂停”；暂停后可以切换任务或修改次数。
8. 点击“停止”会结束当前任务循环。
9. 点击“退出”会停止任务、关闭浮窗并退出脚本。

任务每一步找到目标后，会先随机等待 `100-1000ms` 再点击。点击后的固定等待用于等待下一页加载。

## 浮窗说明

- 任务按钮：切换当前任务。
- 次数按钮：设置本次循环次数。
- 进度文本：显示当前循环进度。
- 开始 / 暂停 / 继续：控制任务运行状态。
- 停止：停止当前任务循环。
- 退出：关闭浮窗并退出脚本。

如果浮窗位置需要微调，可以修改 `config.js` 里的 `floaty.x/y`。`width/height` 默认自适应，通常不要设置。

## 查找红框调试

脚本默认会在每次图片识别时显示一个细红框，红框代表当前查找区域。

如果任务找不到某个图标，先观察红框：

- 红框没有覆盖目标图标：需要调整 `lib/regions.js` 里的区域。
- 红框覆盖了目标图标但仍找不到：通常需要重新截取 `resources/images/` 里的模板图，或降低该步骤的 `threshold`。

如果不想显示红框，可以在 `config.js` 中关闭：

```js
debugRegionOverlay: {
  enabled: false
}
```

## 分辨率适配

当前区域坐标以 `1080x2400` 为基准填写。运行时会按屏幕宽度等比缩放。

常用区域集中在 `lib/regions.js`，任务脚本优先引用这里的命名区域。

支持的区域写法：

- `{ left, bottom, width, height }`：适合底部栏、左侧菜单、出征页按钮、贴底弹窗。
- `{ centerX, centerY, width, height }`：适合屏幕中部弹窗、地图中部目标。
- `{ left, top, right, bottom }`：适合背包物品网格这类需要随屏幕高度变化的大范围区域。
- `[x, y, width, height]`：兼容旧写法，尽量只用于真正固定在顶部或中部的页面。

如果一台新手机和基准手机宽度不同，模板图会按宽度比例缩放。如果 UI 元素实际渲染大小变化较大，可能需要重新截取模板。

## 当前模板

通用模板图放在 `resources/images/`：

- `search_icon.png`：左侧放大镜
- `search_button.png`：搜索按钮
- `camp_1.png`：阵营数字 1 图标
- `march_button.png`：出征按钮

模板定位参考见 [docs/image-reference.md](docs/image-reference.md)。

## 添加自己的任务

添加任务的详细教程见 [docs/add-task-guide.md](docs/add-task-guide.md)。

基本流程：

1. 在 `resources/images/` 下放入新的模板图。
2. 在 `lib/regions.js` 中新增或复用查找区域。
3. 在 `tasks/` 下新增任务脚本。
4. 在 `tasks/index.js` 中注册任务。
5. 在手机上用红框调试区域和模板匹配。

任务中的等待建议统一使用 `ctx.wait(ms)`，这样暂停和停止才能及时生效。
